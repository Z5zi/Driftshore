# Environment / Pierline

Blockout and dressed geometry for **Pierline Marina** (vertical-slice hub).

Suggested folders once authored in-editor:
- `Blockout/` — greybox volumes for docks, slips A–C, Neon Quay, Pier 9 warehouse alley
- `Docks/` — pier meshes, bollards, gangways
- `Facades/` — tourist bars, bait shop, ticket booth
- `Props/` — crates, ropes, life rings, neon signs (original art only)

Coordinate space: map origin near Slip B player start. See `Docs/PIERLINE_MARINA.md` and `Content/Data/`.
